# Raylife

> Public source preview: see [PUBLICATION.md](PUBLICATION.md) for actual checks, known failures and runtime limits.

## Описание

Визуальный эксперимент на Python и Pygame, объединяющий клеточный автомат в духе Game of Life с мягкой трассировкой лучей и цветовым взаимодействием клеток.

Проект строится вокруг цветных клеток с разным поведением: одни пропускают свет, другие отражают, третьи поглощают. За счёт этого обычная клеточная симуляция превращается в живую световую сцену.

## Возможности

- цветная версия Game of Life;
- разные типы клеток с собственным поведением;
- смешивание цветов при выживании и рождении клеток;
- мягкие лучи света от заданных источников;
- интерактивное рисование клеток мышью;
- пауза и выбор типа клетки с клавиатуры.

## Стек

- Python
- Pygame

## Управление

- клавиши `1`–`9` переключают тип клетки;
- левая кнопка мыши рисует клетки;
- правая кнопка мыши стирает клетки;
- `F` ставит симуляцию на паузу и снимает её с паузы.
